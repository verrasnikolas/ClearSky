Τα routes είναι το πρώτο σημείο επαφής για τα εισερχόμενα HTTP requests από τους clients.

Ορίζουν τα URLs και τις μεθόδους HTTP (GET, POST, PUT, DELETE) στα οποία η εφαρμογή θα ανταποκριθεί.

Κάθε route είναι συνδεδεμένο με μια συγκεκριμένη συνάρτηση handler που βρίσκεται σε έναν orchestrator controller.

Όταν ένα αίτημα φτάνει σε ένα route, η συνδεδεμένη συνάρτηση του controller εκτελείται.
